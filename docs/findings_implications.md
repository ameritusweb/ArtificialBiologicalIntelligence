# Findings → Implications

**What this doc is.** The generative middle layer between the experiment
ledgers and the theory registry. Ledgers record verdicts; theories.md
records what crystallized; this doc holds the step between — what a
billed result *means*, and where it leads. Breakthroughs happen here:
implications from separate findings conjoin (F3 × T153 produced the
demand-pull thesis and PC-8-D in one afternoon), and next steps / organ
candidates fall out of the conjunctions, not the findings alone.

**Discipline.** An entry is written when a verdict bills (C13 three-way:
FALSIFIED / VOID / UNTESTED — voids enter too, as method-findings; an
instrument lesson is a finding about the program). Every finding cites
its receipt. Implications are marked speculative until tested. When an
implication crystallizes into a theory, constraint, organ, or spec, the
entry is stamped DISCHARGED with the pointer and kept as history. Cross-
reference findings by ID — conjunctions are where the yield is.

Types: **[W]** world-finding (about the organism/environment),
**[M]** method-finding (about the program's instruments).
